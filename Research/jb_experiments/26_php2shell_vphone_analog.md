# 26. php2shell / java4shell: воспроизведение метода в vphone (Basil)

Дата: 2026-11-26. Тред «Реализация vphone shell». Объект: Basil VM (iOS 27.2 / 24B119, CFW `jb`).

## Вывод

Прямое воспроизведение невозможно: в Procursus (rootless, `/var/jb`) нет ни PHP, ни OpenJDK, а `apt` ставить пакеты не может.
Метод перенесён в виде аналога: исполнение кода в госте из хоста через два готовых канала vphone. Ядро для этого не нужно.

## Что проверено

| Пункт | Результат |
|---|---|
| Референсы | PoC `ikow/php2shell-poc`, `ikow/java4shell-poc` (локальные копии были в `/tmp/jbresearch/ref/`) |
| PHP / OpenJDK в госте | отсутствуют; в Procursus их нет |
| `apt install` | не работает: повреждённые записи dpkg, попытка установки начинает удалять уже установленное (то же видно в заметке 11 про Sileo) |
| Shell из хоста, канал 1 | `script.eval` — исполнение JavaScript в госте от root |
| Shell из хоста, канал 2 | root PTY через `vphone.sock` (`~/.vphone/machines/Basil/vphone.sock`) |
| Готовый помощник | `tools/basil_kcall/bsh.sh <script> [timeout]` (копия: `/tmp/bsh.sh`) — исполняет скрипт в госте; терминальный вывод может терять строки |

## Что не сделано

- apt не чинился (нужна ручная правка записей dpkg — отдельная работа).
- Никакой полезной нагрузки, кроме своих пробников, никуда не ставилось.

## Артефакты

- `tools/basil_kcall/bsh.sh` — помощник «исполнить скрипт в госте через shell-сокет» (пути к сокету и `bash` в госте внутри).
- Каналы описаны в `V2_result.md` (доступ к гостю Basil с хоста).
