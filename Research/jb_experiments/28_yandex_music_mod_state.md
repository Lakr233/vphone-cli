# 28. Мод «Яндекс Музыки» для iOS: состояние на 2026-11-27

Тред «Яндекс Музыка для iOS» (thr_…, родительский — thr_d657gsww3t). Объект: iPhone 17 Pro Max (основная цель), iPhone 13. Источник бандла — VM Basil.

## Подход

Тот же, что для Spotify iOS 9.1.28: свой бандл под подписью пользователя — без рекламы и с показом/поведением «Плюса» в UI. Не готовая чужая сборка. Решение «байт-патч или dylib со swizzle» не принималось: бинарника не было.

## Вывод

Работа остановлена на разведке. **Расшифрованного IPA нет — анализ, сборка, подпись и установка не начаты.** На телефоны ничего не ставилось.

| Пункт | Результат |
|---|---|

Найденные репозитории (все не для iOS-приложения): `Stephanzion/YandexMusicBetaMod` (768★, десктоп, есть `plus-unlocker.ts`), `Vzlomhik2005/Yandex-Music-Mod` (34★, десктоп), `TheKing-OfTime/YandexMusicModClient` (596★, десктоп), `Haker1298/YandexMusic-iOS9` (свой клиент для iOS 9.3.6), `dinozavrik8882/YandexMusicPlus2021.07.4-Free` (Android).

## Что НЕ проверено

- **ID товара `505098110` не подтверждён**: взят по памяти, страница в госте не загрузилась.
- Причина «Cannot Connect» не выяснялась (по решению родительского треда App Store в госте не используется).
- Вторую строку сообщения на экране прочитать не удалось; скриншот снят, но не просмотрен (модель не видит изображения), OCR в госте недоступен.
- `plus-unlocker.ts` десктопного мода не читал; связку «uYou + Yandex» не проверял.
- Путь, которым расшифрованный IPA Spotify попал в Basil, в записях не сохранился.

## На чём остановилось

Ждём решения пользователя об источнике расшифрованного IPA. UI гостя не трогаем.

## Скрипты

Рабочие копии были в `/tmp/ym/`. Перенесены в `tools/ym/` (без секретов; скриншоты и чужие файлы не переносились).

| Скрипт | Назначение |
|---|---|
| `v.py` | основной хелпер. `v.py <method> '<json>' [timeout]` — любой RPC по `vphone.sock`; `v.py shot <name>` — скриншот в `/tmp/ym/shots/`; `v.py ui` — плоское дерево элементов переднего приложения; `v.py ocr` — текст с экрана |
| `sh.py` | `sh.py 'js' 'js' …` — исполнение строк JavaScript в госте через `script.eval` (`fs.ls`, `fs.stat`, `proc.run`), по строке на выражение |
| `ui.sh` | то же дерево элементов через `rpc.sh` + python |
| `rpc.sh` | `rpc.sh method 'json' [timeout]` — RPC через `nc -U` (латиница; кириллица в аргументах ломает JSON) |
| `shot.sh` | `shot.sh name` — скриншот через `nc -U`, ответ обрезается |

Замечания по использованию:

- В этой сборке vphoned параметр называется `bundle_id` (snake_case), не `bundleId`.
- `logs.syslog` с `seconds: N` идёт N секунд реального времени — ставьте таймаут клиента больше.
- `processes.spawn` принимает только `launchctl`, `log`, `ps`.
