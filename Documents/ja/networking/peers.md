# マシン同士の通信

1 台の Mac 上の `nat` マシンは、Bonjour も含めて互いに直接通信できます。仮想 Apple Watch は、この方法で仮想 iPhone とペアリングします。このページでは、1 台のマシンを切り離す方法を説明します。

## マシンを切り離す

```sh
vphone-cli vm config <name> --nat-peers off   # isolate this guest again
vphone-cli vm config <name> --nat-peers on    # the default
```

Launchpad では、マシンの Network 設定にある「Reach other NAT machines」です。変更は次回の起動から反映されます。

切り離したゲストは Mac とインターネットには接続できますが、ほかの仮想マシンには接続できません。切り離しは各マシン自身の接続の設定なので、オプトアウトしたマシンは、ほかのマシンの設定にかかわらず切り離されたままです。

## マシンが参加するネットワーク

| 設定 | 共有ネットワーク | Mac のアドレス |
| --- | --- | --- |
| `--nat-peers on`（標準） | `192.168.65.0/24` | `192.168.65.1` |
| `--nat-peers off` | `192.168.64.0/24` | `192.168.64.1` |

[固定アドレス](addresses.md)（`--ip`）は、マシンが参加するネットワーク上のものでなければなりません。固定アドレスが 1 つ目のネットワーク（`192.168.64.0/24`）上にあるマシンは、ほかのマシンとの通信を求めない限り切り離されたままで、求める場合は 2 つ目のネットワーク上のアドレスが必要です。

## 背景

標準では、Virtualization.framework は Mac の共有ネットワーク上で各 `nat` ゲストをほかのゲストから切り離します。vphone はこの切り離しをオフにし、vmnet は互いに通信するマシンを 2 つ目の共有ネットワーク（1 つ目の次のブロック）に置きます。このスイッチは Virtualization.framework の非公開のものです。これがないバージョンでは、すべてのゲストが切り離されたままになり、仮想マシンの起動時にその旨が表示されます。
