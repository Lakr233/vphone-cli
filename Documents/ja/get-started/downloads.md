# ダウンロード

ダウンロードする Launchpad のバージョンと、それに対応する `VPhone.bundle` を選びます。最新のリリースに公証済みの Launchpad がない場合や、バージョンを手動で合わせる必要がある場合にこのページを使います。

## 各リリースの内容

各[リリース](https://github.com/Lakr233/vphone-cli/releases)には最大 3 つのファイルがあります。

| ファイル | 内容 |
| --- | --- |
| `vphone-launchpad-<version>-notarized.zip` | Apple による署名と公証を受けた Launchpad です。ある場合はこちらをダウンロードしてください。 |
| `vphone-launchpad-<version>.zip` | 公証されていない Launchpad です。初めて開くときに macOS にブロックされます。 |
| `VPhone-<version>.zip` | `VPhone.bundle` です。Launchpad が自動でダウンロードしてインストールするため、このファイルは不要です。 |

公証されていないバージョンを開くには、一度開いてから **システム設定 > プライバシーとセキュリティ** に移動し、**このまま開く** をクリックします。

## Launchpad と VPhone.bundle の対応

Launchpad と同じシリーズの `VPhone.bundle` を使います。シリーズとはバージョンの最初の 2 つの数字のことです。Launchpad 2.2.3 は 2.2 シリーズに属し、どの `VPhone.bundle` 2.2.x とも動作します。

| Launchpad | VPhone.bundle |
| --- | --- |
| 2.15.x | 2.15.x |
| 2.14.x | 2.14.x |
| 2.13.x | 2.13.x |
| 2.12.x | 2.12.x |
| 2.11.x | 2.11.x |
| 2.10.x | 2.10.x |
| 2.9.x | 2.9.x |
| 2.8.x | 2.8.x |
| 2.7.x | 2.7.x |
| 2.6.x | 2.6.x |
| 2.5.x | 2.5.x |
| 2.4.x | 2.4.x |
| 2.3.x | 2.3.x |
| 2.2.x | 2.2.x |
| 2.1.x | 2.1.x |
| 2.0.x | 2.0.x |

同じシリーズの中では、最新の `VPhone.bundle` をインストールしてください。パッチリリースは、Launchpad とバンドルの連携方法を変えずに問題を修正するものです。

Launchpad は古すぎる `VPhone.bundle` を拒否しますが、新しいシリーズのバンドルを一覧に表示することはあります。それらはインストールせず、先に Launchpad をそのシリーズに更新してください。

> [!NOTE]
> Launchpad は自動では更新されません。リリースページから新しいバージョンをダウンロードし、古いアプリと置き換えてください。

## 最近のシリーズで追加されたもの

| シリーズ | 追加 | 備考 |
| --- | --- | --- |
| 2.15 | HomeView | New Machine が `HomeAccessory17,1` と `HomeAccessory17,2` に `homeview` プリセットを選ぶよう、Launchpad 2.15 は同じシリーズのバンドルと組み合わせて使います。 |
| 2.14 | ファイルからのパッチプリセット：プリセットの選択メニューの **Other…**、または `--preset <path>` | Launchpad 2.14 には 2.14 のバンドルが必要です。 |
| 2.13 | Apple TV 4K（第 4 世代） | New Machine が `AppleTV18,1` に `tvos-4k` プリセットを選ぶよう、Launchpad 2.13 は同じシリーズのバンドルと組み合わせて使います。 |

## バージョン 1.x

1.x で作成した仮想マシンは 2.x では起動しません。1.x については [1.0.14 リリース](https://github.com/Lakr233/vphone-cli/releases/tag/1.0.14)をご覧ください。
