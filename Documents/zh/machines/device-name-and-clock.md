# 设备名称与时钟

客户机的设备名称来自虚拟机，时钟和时区来自你的 Mac。如果客户机中的名称或时间与预期不符，请参阅本页。

## 设备名称

要更改客户机显示的名称，请重命名虚拟机：

```sh
vphone-cli vm rename myphone <new-name>
```

客户机会把虚拟机的名称作为设备名称显示，包括在 Xcode 的设备列表和 `xcrun devicectl list devices` 中。

- 无法在客户机内部，或通过访达、Xcode、`idevicename` 重命名设备。这些地方的重命名会报告成功，但实际上什么都不会改变。
- 运行 `vm rename` 后，访达和 `ideviceinfo` 会在虚拟机启动后立即显示新名称。Xcode 和 `devicectl` 在设备出现时读取名称，可能要到再下一次启动才显示新名称。
- 如果虚拟机名称超过 255 个 UTF-8 字节或包含控制字符，则不会被使用；此时客户机显示它自己的名称。

每次启动几秒后，`vphone-vm` 连接到 vphoned 时都会把名称传给客户机，客户机会保留这个名称供下次启动使用。客户机自己的名称仍保存在其偏好设置中，不会被改动。

现有虚拟机迁移到带有此功能的 bundle 后，会在环境更新时获得新的客户机库，并从之后的那次启动开始使用。

实现细节见 [`Research/Guest/device_name_pinning.md`](../../../Research/Guest/device_name_pinning.md)。

## 时钟与时区

客户机跟随 Mac 的时区和时钟，无需任何设置。

每次连接到 vphoned 时，`vphone-vm` 都会发送 Mac 的时区和当时的时间，之后每分钟再发送一次时间。关机一天的客户机，或者在睡眠的 Mac 上挂起的客户机，无需访问 NTP 服务器，一分钟内就会回到 Mac 的时间。与 Mac 相差不到一秒的客户机不会被调整。

要让客户机使用不同的日期或时间：

1. 在客户机中打开**设置 > 通用 > 日期与时间**。
2. 选择日期或时间。这会关闭客户机的自动时间，Mac 的时间也不再应用。

要恢复使用 Mac 的时间，请在同一位置重新打开**自动设置**。
