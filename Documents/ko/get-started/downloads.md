# 다운로드

내려받을 Launchpad 버전과 그에 맞는 `VPhone.bundle`을 고릅니다. 최신 릴리스에 공증된 Launchpad가 없거나 버전을 직접 맞춰야 할 때 이 페이지를 사용하세요.

## 릴리스에 포함된 파일

각 [릴리스](https://github.com/Lakr233/vphone-cli/releases)에는 최대 세 개의 파일이 있습니다.

| 파일 | 내용 |
| --- | --- |
| `vphone-launchpad-<version>-notarized.zip` | Apple의 서명과 공증을 거친 Launchpad입니다. 있으면 이 파일을 내려받으세요. |
| `vphone-launchpad-<version>.zip` | 공증되지 않은 Launchpad입니다. 처음 열 때 macOS가 차단합니다. |
| `VPhone-<version>.zip` | `VPhone.bundle`입니다. Launchpad가 대신 내려받아 설치하므로 이 파일은 필요하지 않습니다. |

공증되지 않은 버전을 열려면 한 번 연 뒤 **시스템 설정 > 개인정보 보호 및 보안**으로 이동하여 **그래도 열기**를 클릭합니다.

## Launchpad와 VPhone.bundle 버전 맞추기

Launchpad와 같은 시리즈의 `VPhone.bundle`을 사용하세요. 시리즈는 버전의 앞 두 숫자입니다. Launchpad 2.2.3은 2.2 시리즈에 속하며 모든 `VPhone.bundle` 2.2.x와 함께 동작합니다.

| Launchpad | VPhone.bundle |
| --- | --- |
| 2.15.x | 2.15.x |
| 2.14.x | 2.14.x |
| 2.13.x | 2.13.x |
| 2.12.x | 2.12.x |
| 2.11.x | 2.11.x |
| 2.10.x | 2.10.x |
| 2.9.x | 2.9.x |
| 2.8.x | 2.8.x |
| 2.7.x | 2.7.x |
| 2.6.x | 2.6.x |
| 2.5.x | 2.5.x |
| 2.4.x | 2.4.x |
| 2.3.x | 2.3.x |
| 2.2.x | 2.2.x |
| 2.1.x | 2.1.x |
| 2.0.x | 2.0.x |

같은 시리즈 안에서는 가장 최신의 `VPhone.bundle`을 설치하세요. 패치 릴리스는 Launchpad와 번들이 함께 동작하는 방식을 바꾸지 않고 문제만 고칩니다.

Launchpad는 자신에게 너무 오래된 `VPhone.bundle`은 거부하지만, 더 새로운 시리즈의 번들은 목록에 표시할 수 있습니다. 그런 번들은 설치하지 말고, 먼저 Launchpad를 해당 시리즈로 업데이트하세요.

> [!NOTE]
> Launchpad는 스스로 업데이트하지 않습니다. 릴리스 페이지에서 새 버전을 내려받아 기존 앱을 교체하세요.

## 최근 시리즈에서 추가된 기능

| 시리즈 | 추가된 기능 | 참고 |
| --- | --- | --- |
| 2.15 | HomeView | New Machine이 `HomeAccessory17,1`과 `HomeAccessory17,2`에 `homeview` 프리셋을 선택하도록 Launchpad 2.15를 같은 시리즈의 번들과 함께 사용하세요. |
| 2.14 | 파일에서 패치 프리셋 불러오기: 프리셋 선택기의 **Other…** 또는 `--preset <path>` | Launchpad 2.14에는 2.14 번들이 필요합니다. |
| 2.13 | Apple TV 4K(4세대) | New Machine이 `AppleTV18,1`에 `tvos-4k` 프리셋을 선택하도록 Launchpad 2.13을 같은 시리즈의 번들과 함께 사용하세요. |

## 1.x 버전

1.x에서 만든 가상 머신은 2.x에서 시작되지 않습니다. 1.x는 [1.0.14 릴리스](https://github.com/Lakr233/vphone-cli/releases/tag/1.0.14)를 참고하세요.
