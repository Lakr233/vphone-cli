# 기기 이름과 시계

게스트는 기기 이름을 가상 머신에서, 시계와 시간대를 Mac에서 가져옵니다. 게스트의 이름이나 시간이 예상과 다를 때 이 페이지를 읽으세요.

## 기기 이름

게스트에 표시되는 이름을 바꾸려면 가상 머신의 이름을 바꿉니다.

```sh
vphone-cli vm rename myphone <new-name>
```

게스트는 가상 머신의 이름을 기기 이름으로 표시하며, Xcode의 기기 목록과 `xcrun devicectl list devices`에도 이 이름이 나타납니다.

- 게스트 안에서, 또는 Finder, Xcode, `idevicename`에서는 기기 이름을 바꿀 수 없습니다. 그곳에서 이름을 바꾸면 성공했다고 표시되지만 아무것도 바뀌지 않습니다.
- `vm rename` 후 머신이 켜지면 Finder와 `ideviceinfo`에는 곧바로 새 이름이 표시됩니다. Xcode와 `devicectl`은 기기가 나타날 때 이름을 읽으므로 다음 부팅까지 이전 이름을 표시할 수 있습니다.
- 가상 머신 이름이 UTF-8로 255바이트를 넘거나 제어 문자를 포함하면 사용되지 않으며, 게스트는 자신의 이름을 표시합니다.

`vphone-vm`은 부팅할 때마다 몇 초 뒤 vphoned에 연결하면서 이름을 게스트에 전달하며, 게스트는 다음 부팅까지 이 이름을 유지합니다. 게스트 자신의 이름은 환경설정에 그대로 남아 있습니다.

이 기능이 있는 번들로 옮긴 기존 머신은 환경 업데이트와 함께 게스트 라이브러리를 받고, 그다음 부팅부터 이를 사용합니다.

구현은 [`Research/Guest/device_name_pinning.md`](../../../Research/Guest/device_name_pinning.md)를 참고하세요.

## 시계와 시간대

게스트는 Mac의 시간대와 시계를 따릅니다. 따로 설정할 것은 없습니다.

`vphone-vm`은 vphoned에 연결할 때마다 Mac의 시간대를 보내고, 그때와 그 뒤 1분마다 Mac의 시간을 보냅니다. 하루 동안 꺼져 있었거나 잠자기 중인 Mac에서 멈춰 있던 게스트도 NTP 서버에 접속하지 않고 1분 안에 Mac의 시간으로 돌아옵니다. Mac과의 차이가 1초 이내인 게스트는 건드리지 않습니다.

게스트에 다른 날짜나 시간을 지정하려면 다음과 같이 합니다.

1. 게스트에서 **설정 > 일반 > 날짜 및 시간**을 엽니다.
2. 날짜나 시간을 선택합니다. 이렇게 하면 게스트의 자동 시간 설정이 꺼지고, Mac의 시간이 더 이상 적용되지 않습니다.

Mac의 시간으로 돌아가려면 같은 곳에서 **자동으로 설정**을 다시 켭니다.
